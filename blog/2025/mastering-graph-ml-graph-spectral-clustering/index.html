Introduction to spectral analysis

To analyze the graph’s structure through the adjacency matrix, we’ll use a powerful mathematical tool from linear algebra: spectral analysis, which focuses on eigenvalues and eigenvectors.

Eigenvalues/vectors are instrumental to understanding electrical circuits, mechanical systems, quantum physics and even Google’s PageRank algorithm.

Also, to understand these concepts better, it is important to know that eigen is a German word meaning own or typical. Hence, an eigenvector can also be called a characteristic vector, and an eigenvalue a characteristic value of a matrix.

Let’s start with a formal definition: for a square matrix A, an eigenvector is a non-zero vector that satisfies the equation

This equation means that when the matrix A acts on the eigenvector, it only scales it by a factor of λ, without changing its direction. This property is important because it identifies inherent directions or patterns in the data, where the scaling factor λ quantifies the importance or strength of that pattern.

Let’s use an example from physics to illustrate this a bit. Imagine a guitar string that vibrates when plucked. The string’s vibration patterns are determined by its physical properties. Each vibration mode corresponds to a specific pattern of movement along the string. For example:

  • The first mode (fundamental frequency) is when the entire string moves up and down uniformly.
  • The second mode is when the string bends into two segments, with a point of no movement in the middle.
  • Higher modes involve increasingly more complex patterns.

These modes are the eigenvectors of the system because they describe the directions in which the string naturally vibrates. Each of these modes vibrates at a specific frequency, which depends on the string’s tension, length, and mass. These frequencies are the eigenvalues of the system associated with an eigenvector (they determine the pitch of the sound produced by the string).

I hope that this part was clear enough for you to understand that eigenvectors and eigenvalues are mathematical tools that allow us to find patterns in the data. I didn’t specify how we can find and calculate them because I just wanted to introduce their motivations, but if you’re interested, you should check [2], [3], and [4].

Graph spectral clustering

Before finally getting to the graph spectral clustering algorithm, I need to introduce the graph Laplacian. This matrix is particularly relevant for graph signal processing as its eigenvectors and eigenvalues will be the center of the spectral analysis of graph signals. The graph Laplacian is defined as

The graph Laplacian measures how different a node is from its neighbors. If all neighbors of a node have similar signal values, the Laplacian value will be small, and if there is a large difference between a node and its neighbors, the Laplacian value will be large.

It also plays a central role in the graph signal processing framework, serving as the graph’s equivalent of the Laplacian operator in classical signal processing, which is fundamental for tasks like filtering, smoothing, and spectral analysis.

Why are we studying the graph Laplacian spectrum? The reason for that is that the graph Laplacian spectrum has several interesting properties about the graph :

  • The smallest eigenvalue of the Laplacian is λ₁​=0, and its eigenvector is a constant vector 1 (all ones). This corresponds to the trivial mode where there is no variation across the graph.
  • The second smallest eigenvalue λ₂, called the algebraic connectivity, measures how well the graph is connected. A larger λ₂ indicates a more connected graph, while λ₂=0 indicates the graph is disconnected.
  • Also, the geometric multiplicity of the 0 eigenvalue (number of independent eigenvectors for which 0 is an eigenvalue) of the Laplacian L corresponds the the number of connected components in the graph.

Finally, the last and most important property (for this article) of this spectrum is: the second-smallest eigenvector of the graph Laplacian is a continuous approximation to the discrete vector that gives an optimal cluster assignment for 2 clusters (with respect to the RatioCut). Generalized graph spectral clustering

The problem with the former property is that this result is only good for getting 2 clusters, but what happens when you want to get more clusters than that?

You can generalize the idea of graph spectral clustering to any arbitrary number of clusters (it still has to be less than the number of nodes). Here are the steps of the algorithm :

  1. Find the K smallest eigenvectors of L (excluding the smallest since it is constant over nodes, so it does not provide much information)
  2. Form the matrix U with the eigenvectors of step 1
  3. Represent each node by its corresponding row in the matrix U
  4. Run K-means clustering on the embeddings from step 3

Let’s illustrate this with an example and take a graph with 10 nodes, in which we want to extract 3 clusters

import networkx as nx
import matplotlib.pyplot as plt

G = nx.erdos_renyi_graph(10, 0.3, seed=42)  # Random graph with 10 nodes
nx.draw(G, with_labels=True, node_color='skyblue', node_size=700)
plt.title("Original Graph")
plt.show()

Then we calculate its adjacency matrix A as explained in my previous article, and its degree matrix D by counting the number of neighbors for each node.

A = nx.adjacency_matrix(G).todense()
D = np.diag(np.sum(A, axis=1))

Then, we have everything we need to compute the graph Laplacian with the formula: L = D - A.

L = D - A
# Or you can directly compute it from the networkx module
L = nx.laplacian_matrix(G).toarray()

After that, we need to get the K=3 smallest eigenvectors of L. For that, I’ll use the scipy built-in module that computes all the eigenvalues of a matrix and its associated eigenvectors.

from scipy.linalg import eigh

eigenvalues, eigenvectors = eigh(L)

You can now extract the three smallest eigenvectors of L to get the matrix U that will represent the nodes in the graph.

K = 3  # Number of clusters
U = eigenvectors[:, 1:K+1]  # Exclude the smallest eigenvector (1st column)

At that moment, you have a 3-dimensional vector representing each node by taking the rows of the U matrix. So the first row represents node n°1, the second row represents node n°2 and so and so on. You can use these representations or embeddings to do traditional clustering using algorithms such as K-means or KNNs. For this example, we’ll use K-means with the scikit-learn Python module.

from sklearn.cluster import KMeans

kmeans = KMeans(n_clusters=K, random_state=0)
labels = kmeans.fit_predict(U)

Finally, you only need to plot the results to see how the generalized spectral algorithm has clustered the nodes in the original graph.

from mpl_toolkits.mplot3d import Axes3D 

plt.figure(figsize=(15, 6))

plt.title("Graph with Clusters")
plt.tight_layout()
plt.show()
